# Privacy Policy — Mohammed Ashraf Security Research

**Last updated:** 12 November 2026

`Mohammed Ashraf Security Research` is a private Pinterest API v5 client operated by an independent security researcher for **authorized security testing under Pinterest's Bug Bounty Program**.

## What data is accessed
- Only the Pinterest account of the researcher (the app owner), using Pinterest's official OAuth 2.0 authorization flow.
- Only the scopes approved by Pinterest for this application are requested and used.

## How data is stored
- OAuth access tokens and refresh tokens are stored locally on the researcher's own workstation.
- No tokens, account data, or test results are sent to any third-party server, analytics service, or advertising network.
- Tokens are rotated and revoked after each testing cycle.

## What is not done
- No data belonging to other Pinterest users is collected, stored, or shared.
- No tracking, profiling, advertising, or data sale.
- No redistribution of Pinterest content.

## Retention
Test artifacts are deleted when the engagement ends or when requested by Pinterest.
